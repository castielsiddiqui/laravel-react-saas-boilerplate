## 🚀 Quick Start Setup

```bash
# 1. Clone the repo
git clone [https://github.com/castielsiddiqui/laravel-react-saas-boilerplate.git](https://github.com/castielsiddiqui/laravel-react-saas-boilerplate.git)

# 2. Install Dependencies
composer install
npm install

# 3. Environment Setup
cp .env.example .env
php artisan key:generate

# 4. Migrate Database
php artisan migrate

# 5. Run Local Servers
php artisan serve
npm run dev
